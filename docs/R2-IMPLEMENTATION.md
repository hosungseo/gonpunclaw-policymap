# PolicyMap R2 구현 메모

R2는 PRD의 P1 범위인 `요약 대시보드`, `정책업무 템플릿`, `정책 기준 레이어`, `데이터 버전·변경점`을 구현한다.
R3의 계정 기반 권한, 임베드, 공개 데이터 API, 지도 디렉터리는 이번 릴리스에 포함하지 않는다.

## 구현 범위

- 공개 지도
  - 현재 조건과 현재 지도 범위의 위치 수 비교
  - 분류별·주소 앞단 기준 행정구역별 개수
  - 대표값 합계·중앙값
  - 집계 CSV 다운로드
- 템플릿
  - `/templates` 카탈로그
  - 복지시설, 생활SOC, 사회적경제기업, 빈집·유휴공간, 안전점검, 관광자원
  - 권장 열, 공개 기본값, 공개 금지 열, 예시 행
  - `/api/templates/[slug]/download` XLSX 생성
  - `map_templates` 테이블을 통한 운영 중 카탈로그 갱신 경로와 정적 fallback
- 정책 기준 레이어
  - `src/data/population-region-index-with-codes.json`의 107개 공통 시군구 코드
  - 인구감소지역 89개: 행정안전부 고시 제2024-15호
  - 인구감소관심지역 18개: 행정안전부 고시 제2025-78호
  - 기존 시군구 경계 GeoJSON과 결합해 표시
  - 지역 클릭 시 해당 지역만 남기는 지도 필터
- 버전
  - `map_versions`에 마커·실패 행·지도 메타데이터 전체 스냅샷 저장
  - 추가·삭제·내용 변경·좌표 변경·포함 여부 변경 계산
  - `/manage/[slug]/versions`에서 이력 확인
  - 복원은 현재 상태를 먼저 보존한 뒤 새 버전을 생성

## 배포 순서

1. Supabase에 `supabase/migrations/0007_r2_workspace.sql`을 적용합니다.
2. 기존 Vercel 환경변수를 그대로 유지하고 새 빌드를 배포합니다.
3. 작은 공개 지도에서 템플릿 다운로드, 기준 레이어, 집계 CSV, 데이터 교체 후 버전 생성과 복원을 확인합니다.

R2 데이터 레이어는 출처와 기준일을 화면에 표시하지만, 인구감소지역 지정 변경 시에는 공통 인덱스 JSON과
기준일을 함께 갱신해야 합니다. 지도에 포함되는 운영 자료 자체의 공개 책임은 업로드 기관에 있습니다.
