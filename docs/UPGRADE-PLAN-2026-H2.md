# GonpunClaw PolicyMap 업그레이드 기획안

- 작성일: 2026-08-04
- 대상 저장소: `hosungseo/gonpunclaw-policymap`
- 기획 범위: 구현 전 제품·데이터·운영 로드맵

## 1. 한 줄 방향

**주소 엑셀을 지도에 찍는 도구에서, 지자체가 지역 현황을 검증·공유·갱신하는 정책지도 스튜디오로 확장한다.**

핵심 사용자는 GIS 담당자가 아니라 복지, 지역경제, 인구, 안전, 관광 등 현업 부서의 공무원이다. 사용자가 별도 교육 없이 엑셀을 올리고, 오류를 고치고, 출처와 기준일이 표시된 지도를 발행하는 데까지 한 흐름으로 끝나야 한다.

## 2. 현재 자산

현재 제품은 다음 기반을 이미 갖추고 있다.

- XLSX·CSV 업로드와 파일 미리보기
- 비동기 주소 변환, 진행률, 실패 주소 확인·재시도
- 다중 지오코더 폴백과 주소 캐시
- 공개 지도와 관리 링크 분리
- 검색, 분류·값 필터, 범례, 표 보기, CSV 내보내기
- 광역시도·시군구·읍면동 행정경계 표시
- 데이터 교체, 공개 여부 변경, 삭제, 신고, 감사 로그
- 민감 컬럼명 감지와 요청 제한

따라서 다음 단계의 우선순위는 새로운 지도 엔진보다 **입력 자유도, 데이터 신뢰도, 반복 관리, 정책 맥락**이다.

## 3. 목표 사용자와 대표 업무

| 사용자 | 시작 자료 | 완성 결과 |
| --- | --- | --- |
| 복지 담당자 | 복지시설·돌봄기관 엑셀 | 지역별 시설 분포와 서비스 공백 지도 |
| 인구정책 담당자 | 정주·청년·빈집 사업 목록 | 인구감소지역 정책사업 현황 지도 |
| 지역경제 담당자 | 전통시장·사회적경제기업 목록 | 업종별 분포와 지원 대상 탐색 지도 |
| 안전 담당자 | 위험시설·민원 발생지 목록 | 내부 점검용 비공개 지도와 조치 현황 |
| 홍보·협업 담당자 | 여러 부서가 관리하는 시설 목록 | 출처·기준일이 명확한 대외 공개 지도 |

## 4. 업그레이드 원칙

1. **업로드 성공보다 발행 신뢰도가 중요하다.** 좌표 품질, 누락, 기준일, 출처를 함께 보여준다.
2. **정해진 A~D열 형식을 완화한다.** 사용자의 기존 엑셀을 최대한 그대로 받아 열을 연결한다.
3. **일회성 발행을 반복 관리로 바꾼다.** 같은 지도에 새 버전을 올리고 변경점을 확인할 수 있어야 한다.
4. **공개와 내부용을 명확히 구분한다.** 민감정보 경고, 공개 전 점검, 관리 권한을 제품 흐름에 넣는다.
5. **지역의 정책 맥락을 기본 레이어로 제공한다.** 행정경계뿐 아니라 인구감소지역 등 공공 기준정보를 선택해 겹쳐 본다.

## 5. 기능 로드맵

### P0 — 업로드 성공률과 데이터 신뢰도

#### 5.1 열 연결 업로드 마법사

- 첫 행을 읽어 `주소`, `이름`, `분류`, `대표값`, `추가정보` 열을 자동 추천
- 사용자가 드롭다운으로 열을 직접 수정
- 주소 열만 필수로 하고 나머지는 선택 사항으로 처리
- 자주 쓰는 연결 방식을 브라우저 또는 계정에 템플릿으로 저장

완료 기준:

- 기존 행정 엑셀의 열 순서를 바꾸지 않고 업로드 가능
- 발행 전에 지도에 공개될 열을 사용자가 명시적으로 확인

#### 5.2 주소 품질 검수 화면

- 변환 성공, 의심, 실패를 분리
- 원주소와 정규화 주소, 지도 좌표를 한 화면에서 대조
- 의심 좌표를 지도에서 이동하거나 주소를 수정해 재시도
- 실패 행만 XLSX·CSV로 내려받아 원자료 담당자에게 회신 가능

완료 기준:

- 성공 건수뿐 아니라 `검수 필요 건수`를 별도 표시
- 발행 전 품질 요약에 공급자별 성공률과 실패 사유 제공

#### 5.3 출처·기준일·갱신일 메타데이터

- 자료 출처, 자료 기준일, 담당 부서, 문의처, 공개 라이선스 입력
- 공개 지도 상단에 `기준일`과 `마지막 갱신일` 표시
- 오래된 지도에는 갱신 필요 배지 표시
- 출처나 기준일이 없는 지도는 공개 전에 경고

### P1 — 정책지도 스튜디오

#### 5.4 요약 대시보드

- 전체 개수, 분류별 개수, 행정구역별 개수, 대표값 합계·중앙값
- 지도 이동 범위에 맞춰 요약 수치 갱신
- 표와 차트를 이미지 또는 CSV로 내보내기
- 분류와 수치가 없는 단순 위치 지도에서는 불필요한 위젯 자동 숨김

#### 5.5 정책용 시작 템플릿

- 복지시설, 생활SOC, 사회적경제기업, 빈집·유휴공간, 안전점검, 관광자원 템플릿
- 템플릿마다 권장 열, 공개 금지 열, 예시 데이터를 함께 제공
- `빈 엑셀 다운로드 → 작성 → 업로드`와 `기존 엑셀 연결` 두 경로 지원

#### 5.6 기준 레이어

- 인구감소지역·인구감소관심지역 표시
- 선택 지역으로 지도 범위와 필터를 즉시 제한
- 공통 행정구역 코드로 업로드 자료를 시군구·읍면동에 연결
- 향후 신뢰 가능한 공공데이터만 선택형 레이어로 추가

#### 5.7 버전과 변경점

- 데이터 교체 시 이전 버전 보존
- 추가·삭제·수정 위치 개수와 변경 목록 표시
- 특정 버전으로 되돌리기
- 공개 지도에는 최신본만 노출하고 관리 화면에서 이력 확인

### P2 — 협업과 재사용

#### 5.8 공개 범위와 협업

- 공개, 링크 보유자, 비공개 3단계
- 지도 소유자·편집자·검토자 역할
- 공개 전 검토 체크리스트와 승인 기록
- 관리 토큰 방식은 유지하되 계정 기반 관리는 선택적으로 추가

#### 5.9 임베드와 데이터 API

- 지자체 홈페이지용 반응형 iframe 코드
- 현재 필터 상태를 포함한 공유 링크
- 공개 지도용 GeoJSON·JSON 읽기 API
- 출처, 기준일, 이용조건을 API 응답에도 포함

## 6. 인구감소지역 부동산 프로젝트와의 연결

두 제품은 합치지 않고 역할을 나눈다.

- 인구감소지역 부동산: 국가 단위의 지정 현황, 특례, 시장 흐름을 설명하는 **기준 탐색기**
- PolicyMap: 지자체가 자기 지역의 시설·사업·자원을 올리는 **현장 데이터 발행 도구**

연결 방식:

1. 공통 시군구 코드와 지역명 정규화 파일을 공유한다.
2. PolicyMap에서 인구감소지역을 기본 레이어로 켤 수 있게 한다.
3. 부동산 프로젝트 지역 상세에서 해당 지역의 공개 PolicyMap을 연결한다.
4. 양쪽 데이터에 출처, 기준일, 갱신일을 같은 형식으로 기록한다.

## 7. 구현 순서

### 1차 릴리스 — 믿고 올릴 수 있는 업로드

- 열 연결 마법사
- 주소 품질 검수
- 출처·기준일 메타데이터
- 공개 전 확인 화면

### 2차 릴리스 — 업무에 쓰는 지도

- 요약 대시보드
- 정책용 템플릿
- 인구감소지역 기준 레이어
- 데이터 버전과 변경점

### 3차 릴리스 — 조직이 함께 쓰는 지도

- 협업 권한과 승인
- 임베드
- 공개 데이터 API
- 공개 지도 디렉터리와 우수 사례

## 8. 성공 지표

| 지표 | 목표 |
| --- | --- |
| 첫 업로드 완료율 | 업로드 시작자의 70% 이상 |
| 주소 변환 자동 성공률 | 일반적인 도로명·지번 주소 기준 95% 이상 |
| 첫 파일 선택부터 지도 발행까지 | 중앙값 5분 이내 |
| 기준일·출처 입력률 | 공개 지도의 90% 이상 |
| 30일 내 데이터 재갱신 | 발행 지도의 20% 이상 |
| 공개 전 민감정보 사고 | 0건 |

## 9. 이번 업그레이드에서 하지 않을 것

- 범용 GIS 편집기 수준의 도형 편집
- 민감한 개인 위치정보 저장
- 검증되지 않은 공공데이터 레이어의 대량 탑재
- 초기 단계의 복잡한 기관용 과금·조직관리
- AI가 위치나 행정 판단을 확정하도록 하는 기능

## 10. 바로 시작할 구현 백로그

1. `maps`에 출처·기준일·담당 부서·갱신주기 필드 추가
2. 업로드 열 연결 규격과 마이그레이션 설계
3. 변환 결과를 `성공/검수 필요/실패`로 나누는 품질 규칙 정의
4. 공개 전 확인 화면의 민감정보·출처·기준일 체크리스트 제작
5. 공통 지역 코드 패키지를 두 저장소에서 읽는 방식 결정
