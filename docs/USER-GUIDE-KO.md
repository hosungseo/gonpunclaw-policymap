# GonpunClaw PolicyMap 사용 안내

## 1. 접속
- 서비스 주소: <https://gonpunclaw-policymap.vercel.app>
- 샘플 지도: <https://gonpunclaw-policymap.vercel.app/demo>
- 업로드 페이지: <https://gonpunclaw-policymap.vercel.app/upload>
- 업무별 템플릿: <https://gonpunclaw-policymap.vercel.app/templates>

## 2. 무엇을 하는 서비스인가
기존 업무 엑셀을 업로드하면 열 역할과 공개 범위를 확인하고 주소 품질을 검수한 뒤 정책지도로 발행하는 서비스입니다.
샘플 지도에서는 파일을 올리지 않아도 검색, 필터, 표 보기를 먼저 체험할 수 있습니다.

활용 예시:
- 정책사업 대상지 위치 시각화
- 지원시설 분포 지도
- 거점기관 위치 공유
- 현장 점검 대상지 맵 만들기

업무별로 바로 시작하려면 [업무별 템플릿](https://gonpunclaw-policymap.vercel.app/templates)에서
복지시설, 생활SOC, 사회적경제기업, 빈집·유휴공간, 안전점검, 관광자원용 XLSX를 내려받을 수 있습니다.
각 템플릿은 권장 열과 공개 주의사항을 함께 안내합니다.

## 3. 권장 파일 형식
- 권장: `.xlsx`
- 가능: `.xls`, `.csv`
- 기본 제한: 10,000행, 3MB
- 현재 실사용 기준으로는 `.xlsx`가 가장 안정적입니다.

## 4. 엑셀 파일 형식
기본 구조는 아래와 같습니다. 고정된 A~D 순서가 아니어도 헤더와 표본을 바탕으로 열 역할을 추천합니다.

한 행은 지도에 표시될 위치 1개입니다. 예를 들어 시설 10개를 올리려면 헤더 아래에 데이터 행을
10개 넣으면 됩니다. 여러 시트가 있으면 업로드 화면에서 사용할 시트를 선택합니다.

예를 들어 아래 한 줄은 지도에서 `예시복지관` 위치 1개로 표시됩니다.

| 주소 열 | 이름 열 | 대표값 열 | 분류 열 | 공개 추가정보 |
| --- | --- | --- | --- | --- |
| 서울 서초구 반포대로 58 | 예시복지관 | 48 | 복지 | 담당부서, 비고 |

| 열 | 의미 | 예시 |
| --- | --- | --- |
| 주소 열 | 주소 | 세종특별자치시 도움6로 11 |
| 이름 열 | 이름 | 정부세종청사 |
| 대표값 열 | 숫자로 변환할 값 | 100 |
| 분류 열 | 필터에 사용할 분류 | 행정 |
| 공개 추가정보 | 공개 팝업에 표시할 선택 정보 | 담당부서, 비고 등 |

### 최소 조건
- 주소 역할로 연결한 열은 필수입니다. 기본 추천은 `주소`, `소재지`, `도로명`, `address` 같은 헤더를 우선합니다.
- 이름·대표값·분류는 선택이며 사용자가 추천을 바꿀 수 있습니다.
- 주소가 비어 있는 행은 자동으로 제외될 수 있습니다.
- 추가정보는 공개할 열만 개별 선택합니다. 선택하지 않은 열은 지도 데이터에 저장하지 않습니다.
- 전화번호, 이메일, 계좌, 주민번호, 상세주소 같은 민감 정보는 검사합니다. 고위험 정보가 공개 대상이면
  업로드가 중단되고, 조직 대표 연락처처럼 허용 가능한 항목은 확인 후 진행할 수 있습니다.

## 5. 파일 검사와 열 연결

파일을 고르면 다음 항목을 먼저 확인합니다.

- 사용할 시트
- 헤더와 데이터 행 수
- 빈 행과 주소 누락 행
- 중복 가능 주소 수
- 대표값 숫자 변환 성공·실패 통계
- 주소·이름·대표값·분류 역할 추천
- 공개 추가정보 열과 민감 가능 열

추천이 맞지 않으면 각 역할의 열을 직접 바꿉니다. 주소 열은 반드시 연결해야 하며, 공개하지 않을 열은
추가정보 선택을 해제합니다.

## 6. 업로드 화면에서 입력하는 값
### 지도 제목
예: `세종 공공시설 분포`

### 설명
예: `2026년 기준 주요 공공시설 위치`

### 값 컬럼 라벨
예: `사업비`, `인원`, `면적`

대표값은 위치 1개에 붙일 숫자 1개입니다. 여러 숫자 지표가 필요하면 대표값 하나를 선택하고,
나머지는 공개 추가정보 열로 선택하는 편이 좋습니다.

### 단위
예: `억원`, `명`, `㎡`

### 분류 컬럼 라벨
예: `기관유형`, `사업유형`

## 7. 주소 품질 검수와 발행

주소 변환 결과는 `성공`, `검수 필요`, `실패`로 나뉩니다. 검수 필요 사유에는 행정구역 불일치,
낮은 정합도, 동일 좌표 중복 등이 포함됩니다.

- 검수 필요 행은 주소를 수정해 재변환할 수 있습니다.
- 좌표를 직접 입력하면 수동 보정으로 기록됩니다.
- 발행 대상에서 제외할 행을 선택할 수 있습니다.
- 실패·제외 행은 CSV로 내려받을 수 있습니다.

출처, 자료 기준일, 담당 부서 또는 관리 주체를 입력해야 공개·링크 공개로 발행할 수 있습니다.
공개 범위는 다음 세 가지입니다.

- `공개`: 사이트맵과 검색 노출 대상
- `링크 보유자`: 링크를 가진 사람만 접근, 사이트맵·디렉터리 제외
- `비공개`: 공개하지 않고 관리 토큰으로만 관리

발행 직전 데이터 건수, 품질 상태, 공개 열, 출처·기준일과 민감정보 확인을 체크합니다.

## 8. 업로드 후 받게 되는 것
파일을 제출하면 주소 변환 작업이 시작됩니다. 화면에는 전체 주소 수, 처리한 주소 수, 성공/실패
개수가 표시됩니다. 작업이 끝나면 아래 정보가 생성됩니다.

### 지도 링크
- `공개`로 발행한 링크는 누구나 볼 수 있고 외부 공유용으로 사용합니다.
- `링크 보유자`는 링크를 아는 사람에게만 공유하며 사이트맵·검색에는 노출되지 않습니다.
- `비공개`는 공개 지도 화면을 열 수 없고 관리 토큰으로만 관리합니다.

### 관리 페이지 URL
- 업로드한 지도를 수정하거나 삭제할 수 있는 페이지입니다.
- 지도 소유자 또는 내부 운영자에게만 공유해야 합니다.

### 관리 토큰
- 수정/삭제에 꼭 필요합니다.
- 업로드 직후 안전한 곳에 따로 저장해야 합니다.
- 잃어버리면 관리가 어려워집니다.
- 공개 지도 이용자에게 전달하면 안 됩니다.

## 9. 수정과 삭제
관리 페이지(`/manage/[slug]`)에서 아래 작업이 가능합니다.
- 제목 수정
- 설명 수정
- 값/단위/분류 라벨 수정
- 엑셀 데이터 교체
- 현재 지도 데이터 CSV 내보내기
- 좌표 변환 실패 주소만 다시 시도
- 공개 여부 변경
- 지도 삭제

### 버전과 변경점

관리 페이지의 `버전·변경점`에서 데이터 교체와 발행 이력을 확인할 수 있습니다.

- 추가·삭제·내용 변경·좌표 변경·포함 여부 변경 건수를 확인합니다.
- 이전 데이터는 전체 스냅샷으로 보존됩니다.
- 복원하면 현재 상태도 새 버전으로 보존한 뒤 선택한 버전을 새 버전으로 생성합니다.
- 복원은 관리 토큰이 필요하며 공개 링크 주소는 유지됩니다.

## 10. 요약 대시보드와 정책 기준 레이어

공개 지도 왼쪽의 `R2 요약 대시보드`는 현재 조건과 현재 지도 범위를 나누어 보여줍니다.
대표값 열이 있으면 합계와 중앙값을 계산하고, 분류별·주소 앞단 기준 행정구역별 분포를 함께 표시합니다.
집계 CSV 버튼으로 현재 조건의 요약을 내려받을 수 있습니다.

`정책 기준 레이어`를 켜면 행정안전부 고시 기준의 인구감소지역 89개와 인구감소관심지역 18개가
시군구 경계에 표시됩니다. 지역을 클릭하면 해당 지역만 남겨 현장 자료와 정책 기준을 함께 볼 수 있습니다.
레이어에는 출처, 고시번호, 기준일을 표시하며 상세 기준은 [법령정보센터](https://www.law.go.kr/)에서
확인할 수 있습니다.

엑셀 데이터 교체는 기존 공개 링크와 관리 토큰을 유지한 채 마커 데이터만 새 파일 내용으로 바꿉니다.
기존 지도에서 선택한 열 연결을 유지하며, 새 파일의 주소, 이름, 대표값, 분류, 공개 추가 정보가 현재 지도 데이터를 대체합니다.

CSV 내보내기는 현재 지도에 등록된 마커와 공개 추가 정보를 내려받습니다. 실패 주소 재시도는
기존 성공 마커를 지우지 않고, 실패 목록에 남은 주소만 다시 좌표 변환합니다.

## 10-1. 공유·임베드·검토 (R3)

- **공유**: 공개 지도 화면 오른쪽 위 ‘공유’에서 현재 필터가 담긴 링크, 홈페이지에 넣을 iframe 코드, 데이터 API 주소를 복사할 수 있습니다. 링크와 임베드는 지금 선택한 분류·값 범위·검색어·보기 상태를 그대로 엽니다.
- **공개 지도 둘러보기**: `/maps`에서 공개 범위를 ‘공개’로 발행한 지도를 검색합니다. 링크 공개 지도는 목록에 나오지 않습니다. 운영자가 디렉터리에서 숨긴 지도는 목록·사이트맵에서만 빠지고 링크로는 계속 열립니다.
- **데이터 API**: `/api/public/maps/{slug}`(JSON), `/api/public/maps/{slug}/geojson`(GeoJSON)으로 공개·링크 공개 지도의 데이터를 받을 수 있습니다. 자세한 내용은 [PUBLIC-API.md](./PUBLIC-API.md)를 참고하세요.
- **공개 전 검토**: 관리 페이지 ‘검토·승인’에서 ‘공개 전 검토 필수’를 켜면 검토 링크가 한 번 표시됩니다. 검토자에게 링크를 전달하고 ‘검토 요청’을 누르세요. 검토자가 체크리스트를 확인해 승인하면 비공개 → 공개 전환이 가능해집니다. 반려 의견은 관리 페이지에 표시됩니다. 승인 뒤 데이터를 교체·복원하거나 출처·출처 URL·기준일·담당 부서를 수정하면 ‘재검토 필요’로 바뀌어 다시 요청해야 합니다. 검토 링크를 재발급하면 이전 링크는 즉시 무효가 됩니다.

## 11. 주의사항
- 주소는 가능한 한 도로명 기준으로 정확하게 쓰는 편이 좋습니다.
- 너무 모호한 주소는 좌표 변환이 실패할 수 있습니다.
- 현재 운영 기준으로는 `.csv`보다 `.xlsx` 업로드를 권장합니다.
- 공개할 열에 개인정보나 민감정보가 들어 있지 않은지 발행 전에 확인해야 합니다.
- 관리 토큰은 반드시 별도 보관해야 합니다.
- 공개 링크는 외부 공유용이고, 관리 페이지 링크와 관리 토큰은 내부 보관용입니다.
- CSV 내보내기 파일에도 공개 지도 데이터와 추가 정보가 들어 있으므로 내부 보관 기준에 맞게 다뤄야 합니다.

## 12. 가장 쉬운 사용 순서
1. 엑셀을 `.xlsx`, `.xls` 또는 `.csv`로 저장
2. `/upload` 접속
3. 제목과 파일을 입력하고 사용할 시트·열 역할을 확인
4. 공개 추가정보 열과 공개 범위를 선택
5. 주소 변환 진행률과 검수 필요·실패 행을 확인
6. 출처·기준일·관리 주체를 입력해 발행
7. 링크와 관리 토큰을 안전하게 보관

## 13. 추천 첫 테스트
먼저 샘플 지도에서 결과 화면을 확인하고, 이후 2~5행짜리 작은 파일로 업로드를 테스트한 뒤
실제 대량 파일을 올리는 것을 권장합니다.
